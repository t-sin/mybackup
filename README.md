# mybackup

My backup tool, a successor of [backup.sh](https://github.com/t-sin/backup.sh).

## Usage

1. Create a config file from [`example_mybackup.config.yaml`](example_mybackup.config.yaml) to define backup targets and log settings.
2. Run `/path/to/mybackup /path/to/mybackup.config.yaml`

## Requirements

- Ruby 4.x
